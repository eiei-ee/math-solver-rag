# Prompt 优化前后对比记录

## 对比一：有无 COSTAR 框架

### 优化前（无 COSTAR）

```
你是一位数学老师，请用中文解答数学题。使用 LaTeX 格式输出数学公式。
```

**测试题目**：解方程 $x^2 - 5x + 6 = 0$

**优化前回答（摘要）**：
> 使用求根公式：$x = \frac{5 \pm \sqrt{25-24}}{2} = \frac{5 \pm 1}{2}$，所以 $x=3$ 或 $x=2$。

**问题**：缺少题目分析、缺少步骤说明（判别式未显式计算）、缺少验证、没有易错点提醒。

### 优化后（COSTAR）

```
## Context: 你是一位经验丰富的高中/大学数学教师
## Objective: 给出详细的逐步推导过程，每一步说明依据
## Style: 严谨学术风格
## Tone: 耐心、鼓励式
## Audience: 学生
## Response: LaTeX 格式，含分析→推导→答案→总结
```

**优化后回答（摘要）**：
> **题目分析**：一元二次方程 $x^2 - 5x + 6 = 0$，标准形式 $ax^2+bx+c=0$，其中 $a=1, b=-5, c=6$。
>
> **解法一（因式分解）**：$x^2 - 5x + 6 = (x-2)(x-3) = 0$，得 $x_1=2, x_2=3$
>
> **解法二（求根公式）**：$\Delta = b^2-4ac = (-5)^2 - 4 \times 1 \times 6 = 25 - 24 = 1$，$x = \frac{5 \pm 1}{2}$
>
> **验证**：代入 $x=2$：$4-10+6=0$ ✓；代入 $x=3$：$9-15+6=0$ ✓
>
> **易错提醒**：注意 $b=-5$ 代入公式时，$-b = 5$，不要写成 $-5$。

**优化效果**：
- 增加了题目分析环节
- 提供了两种解法
- 显式计算判别式
- 带验证步骤
- 指出常见错误

## 对比二：有无负向提示词

### 测试题目

求函数 $f(x) = \ln(x^2 - 3x + 2)$ 的定义域。

### 无负向提示词

> $x^2 - 3x + 2 > 0$，即 $(x-1)(x-2) > 0$，所以 $x > 2$ 或 $x < 1$。
> 定义域为 $(-\infty, 1) \cup (2, +\infty)$。

**问题**：没错但不够细致，没有说明为什么只需 $x^2-3x+2 > 0$，没有提到对数函数的定义要求。

### 有负向提示词

添加了：
- 禁止跳过推导步骤
- 禁止忽略定义域限制

> **分析**：对数函数 $y = \ln u$ 的定义要求真数 $u > 0$。本题中 $u = x^2 - 3x + 2$。
>
> **步骤1**：令 $x^2 - 3x + 2 > 0$
> **步骤2**：因式分解 $(x-1)(x-2) > 0$
> **步骤3**：用数轴穿根法或符号表判断：开口向上的二次函数，两根为 $x=1$ 和 $x=2$，不等式大于零取「两根之外」。
>
> $x < 1$ 或 $x > 2$
>
> **答案**：定义域为 $(-\infty, 1) \cup (2, +\infty)$
>
> **易错提醒**：不要漏掉 $x=1$ 和 $x=2$ 这两个边界点 — 对数真数不能等于 0，所以边界应使用开区间。

**优化效果**：
- 补充了「为什么」需要讨论真数 > 0
- 说明了求解方法的依据（数轴穿根法）
- 提醒了区间开闭的易错点

## 对比三：有无 RAG 知识库检索

### 测试题目

已知椭圆 $\frac{x^2}{4} + \frac{y^2}{3} = 1$，过右焦点的直线与椭圆交于 A、B 两点。求 AB 中点轨迹。

### 无 RAG

> 设直线方程为...（跟随通用数学能力推导，可能忽略椭圆第二定义或其他巧妙解法）

### 有 RAG

> 检索到参考资料：
> - 椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 的焦点 $F(\pm c, 0)$，$c = \sqrt{a^2-b^2}$
> - 点差法：$k_{AB} \cdot k_{OM} = -\frac{b^2}{a^2}$
>
> 使用点差法可快速求解...

**优化效果**：RAG 提供了一个「点差法」捷径，使解答更简洁，同时保证了公式的正确性。

---

## 总结

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| COSTAR 框架 | 简单一句话 | Context/Objective/Style/Tone/Audience/Response 六要素 |
| 推导步骤 | 可能跳步 | 每步编号，有依据 |
| 验证环节 | 缺失 | 代回原题检验 |
| 易错提醒 | 缺失 | 明确指出常见陷阱 |
| 负向提示词 | 无 | 约束跳步、未验证、忽略定义域等行为 |
| 格式规范 | 可能不规范 | 统一 LaTeX |
| RAG 增强 | 无 | 检索公式定理辅助解答 |
