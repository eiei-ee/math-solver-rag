# 高考真题 — 函数与导数

**题目**：已知函数 $f(x) = x^3 - 3x + 1$。

1. 求 $f(x)$ 的单调区间和极值。
2. 若方程 $f(x) = k$ 有三个不同实根，求 $k$ 的取值范围。

**解答**：

(1) $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$

令 $f'(x) = 0$ 得 $x = -1$ 或 $x = 1$

当 $x < -1$ 时 $f'(x) > 0$，$f(x)$ 递增
当 $-1 < x < 1$ 时 $f'(x) < 0$，$f(x)$ 递减
当 $x > 1$ 时 $f'(x) > 0$，$f(x)$ 递增

极大值 $f(-1) = -1 + 3 + 1 = 3$
极小值 $f(1) = 1 - 3 + 1 = -1$

(2) 当 $-1 < k < 3$ 时，直线 $y = k$ 与曲线有三个交点。
