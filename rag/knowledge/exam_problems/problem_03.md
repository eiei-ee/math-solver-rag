# 高考真题 — 解析几何

**题目**：已知椭圆 $\frac{x^2}{4} + \frac{y^2}{3} = 1$，过右焦点 $F$ 的直线 $l$ 与椭圆交于不同的两点 $A$、$B$。求线段 $AB$ 的中点到直线 $x=4$ 的最短距离。

**解答**：

椭圆参数：$a^2 = 4, b^2 = 3$，所以 $c = \sqrt{a^2 - b^2} = 1$

右焦点 $F(1, 0)$。

设直线 $l$ 的方程为 $y = k(x - 1)$，代入椭圆方程：

$\frac{x^2}{4} + \frac{k^2(x-1)^2}{3} = 1$

整理得 $(3+4k^2)x^2 - 8k^2 x + (4k^2 - 12) = 0$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：
$$x_1 + x_2 = \frac{8k^2}{3+4k^2}$$

中点横坐标：
$$x_m = \frac{x_1 + x_2}{2} = \frac{4k^2}{3+4k^2}$$

中点到 $x=4$ 的距离：$d = |4 - x_m| = \left|4 - \frac{4k^2}{3+4k^2}\right|$

当 $k=0$ 时，$x_m = 0$，$d = 4$
当 $k \to \infty$ 时，$x_m \to 1$，$d = 3$

最短距离为 $3$。
